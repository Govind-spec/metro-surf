# Metro Surf (Metro Dash: Overdrive)

A high-performance, stylized 3D cartoon endless runner game built with **Three.js** and HTML5/CSS/JavaScript.

## Features

- **Expressive 3D Cartoon World**: Dynamic environment with mall-city skyline, stylized subway train cars, obstacles, ramps, and tracks.
- **Classic Subway Runner Gameplay**: 3-lane dodge mechanics, jumping, sliding, rail grinding, and obstacle navigation.
- **Power-ups & Collectibles**: Coin magnets, jetpacks, super sneakers, score multipliers, and mystery boxes.
- **Responsive Arcade Controls**:
  - `A` / `D` or `Left` / `Right` Arrow keys: Switch lanes
  - `W` / `Up` Arrow key or `Space`: Jump
  - `S` / `Down` Arrow key: Slide / Duck
  - Touch gestures (swipe left, right, up, down) for mobile / tablet devices
- **Stylized Visuals**: Custom shader effects, toon outlines, particle systems, squash & stretch animations, and retro-modern typography.

## Quick Start

Simply open `endless_runner.html` in any modern web browser or serve it using any local static web server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Then visit `http://localhost:8000/endless_runner.html`.
